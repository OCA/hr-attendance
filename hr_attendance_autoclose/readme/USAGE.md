1. Go to *Attendances ▸ Configuration ▸ Settings*.
2. Enable **Automatically Check-Out Employees** and set a **tolerance** in hours.
3. Go to *Attendances ▸ Manage Attendances ▸ Attendances*.
4. The system will automatically check out any open attendance if the total hours worked in the day (including past check-ins) exceeds the defined hours per day plus the tolerance.
