To configure breaks:

1. Go to *Attendances > Configuration > Break Types* and review the break
   types. *Paid Break* and *Unpaid Break* are created on installation.
2. Go to *Attendances > Configuration > Reasons* and create a reason
   for each kind of break (for example *Coffee Break* and *Lunch Break*), with
   *Action Type* set to *Sign out*, *Show on attendance screen?* checked and the
   matching *Break Type*.
3. Go to *Attendances > Configuration > Settings* and, under *Attendance Reasons*, enable showing the reasons on the
   attendance screen, so employees can pick the break reason when checking
   out. To keep checking out at the end of the day free of friction, leave the
   reason optional.
4. Optionally, in the *Break Rounding* setting, enter the number of minutes
   each break should be rounded to (for example 5 or 15). Leave it at `0` to
   keep the exact break duration (default).
