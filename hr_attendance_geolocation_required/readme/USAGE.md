1.  Go to _Settings > Attendances_ and enable the option **Require Geolocation for
    Attendance** to make GPS coordinates mandatory for check-in/check-out in kiosk mode.
    This setting is company-specific.
2.  Ensure that geolocation services are enabled on the employee's device.
3.  Open _Attendances > Manage Attendances > Kiosk Mode_.
4.  Employees attempting to check in or out must allow location access in their browser.
5.  If location access is denied, a notification appears instructing the user to enable
    geolocation.
