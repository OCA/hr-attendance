HR Attendance Geolocation Required

This module ensures that employees cannot check in or out unless their device has geolocation enabled.

Usage

  1. Go to Attendances > Configuration > Configuration.
  2. Ensure that geolocation is required for attendance tracking.
  3. Employees must allow GPS and browser location permissions to check in or out.
  4. If location is not enabled, the system will prevent attendance and show an error message.
