User Permissions Required
To access attendance reports, users must have HR permissions:

Go to Settings → Users & Companies → Users
Select the target user
In the Access Rights tab, assign one of these groups:

Human Resources / User - for read-only access to reports
Human Resources / Manager - for full access and data management



Permission Levels:

HR User (hr.group_hr_user): View and generate reports only
HR Manager (hr.group_hr_manager): Full access to create, modify, and delete attendance data

Module Setup

Install the HR Attendance Report module
Ensure HR and HR Attendance base modules are active
Assign appropriate HR permissions to users
Module is ready to use

Security Notes:

Only users with HR permissions can access attendance reports
This restriction protects sensitive employee attendance data
Regular users (base.group_user) cannot access these reports
