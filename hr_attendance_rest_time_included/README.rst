This module extends `hr_attendance` to manage employee rest times included in working time, supporting multiple breaks per attendance.

**Table of contents**

.. contents::
   :local:

Usage
=====

#. Go to *Attendances > Configuration*.
#. Create the reasons that cause the rest time.
#. Set the rest time reason.
#. Now when yosu check out with that reason it includes the rest time.

Known issues / Roadmap
======================

Not fully compatible with hr_attendance_geolocation.
Sign-out coordinates are stored in the main attendance record when signing out rest time.
In upper versions with geolocation, we need to review compatibility.

Also not fully compatible with hr_attendance_modification_tracking. 
Tracking not working correctly for the model hr_attendance_rest_time.
In upper odoo version tracking is part of core, we need to review.
