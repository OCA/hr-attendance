Use Cases / Context
===================

When an HR manager tries to get extra hours information of their
employees, Odoo will only display information related to attendances.

However, there can be extra hour records related to time off allocations
or requests. That information is also relevant, but is hidden by
default.

HR managers that extra hours information of their employees will
appreciate the new menu that this module provides, where they will find
that information.

Configuration
=============

No configuration needed. Requires existing attendance records to display
data.

Usage
=====

1. Go to **Employees > Reporting > Extra Hours**

|menu|

2. View overtime from all sources.
3. Use filters to distinguish between overtime types
4. Switch between Pivot, List, Calendar, and Graph views for different
   analyse
